# 🏯 한국사 탐험대 — 초등 한국사 학습 앱

고조선부터 조선 초기까지, 초등학생이 **배우고 · 퀴즈 풀고 · 태블릿 펜으로 직접 써 보는** 상호작용형 한국사 학습 웹앱입니다.

## 기능

- **📖 배우기** — 6개 시대(선사 → 고조선 → 삼국·가야 → 통일신라·발해 → 고려 → 조선 초기)를 아코디언 카드로 학습
- **✅ 퀴즈** — 객관식 12문항, 선택 즉시 정답·해설 피드백 + 점수
- **✏️ 문제풀기** — OX 문제 + 빈칸 채우기, 즉시 채점
- **🖊️ 쓰기 연습** — HTML Canvas 필기판 (펜 필압·색·굵기·지우개·되돌리기·따라쓰기 가이드)
- 진도·점수는 브라우저 `localStorage`에 저장

## 실행

별도 빌드 없이 `index.html`을 브라우저로 열면 됩니다. 로컬 서버로 보려면:

```bash
python -m http.server 4173
# http://localhost:4173/korean-history-edu/ 접속
```

태블릿에서는 브라우저로 열어 펜/손가락으로 바로 쓸 수 있습니다.

## 내용 정확성

초등학교 사회과 교육과정(한국사 영역)의 흐름에 맞춰 정리했으며, 연도·인물·사건은 널리 인정되는 통설(예: 『삼국유사』 기록에 따른 고조선 건국 기원전 2333년)만 사용했습니다. 정확한 학습을 위해 아래 **국가 공인 자료**와 함께 확인하세요.

- [에듀넷·티클리어](https://www.edunet.net) (교육부)
- [우리역사넷](https://contents.history.go.kr) (국사편찬위원회)
- [국립중앙박물관](https://www.museum.go.kr)

## 기술

순수 HTML/CSS/JS 단일 파일, 외부 의존성 없음(폰트 Pretendard CDN만 사용). 모바일 퍼스트·접근성(키보드·명도대비)·`prefers-reduced-motion` 대응. `website-builder-pro` 스킬의 디자인 토큰을 아동용으로 조정해 제작했습니다.
