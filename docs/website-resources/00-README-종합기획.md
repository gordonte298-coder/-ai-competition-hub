## 🎯 프로젝트 비전

**하나의 사이트, 세 가지 얼굴:**

```
┌─────────────────────────────────────────────┐
│                 🏠 메인 허브                  │
│      (인상적인 히어로 + 3개 영역 입구)          │
├───────────────┬──────────────┬──────────────┤
│   🎮 게임 존   │  📚 스터디 존  │ 👤 포트폴리오  │
│  미니게임 모음  │ 영어·스페인어  │  나의 프로젝트  │
│  랭킹·공유     │ 단어장·퀴즈    │  소개·연락처   │
└───────────────┴──────────────┴──────────────┘
```

**핵심 아이디어: 세 영역이 서로를 살린다**
- 게임 존의 게임 중 일부를 **어학 게임**으로 만들면 두 영역이 자연스럽게 연결됨 (예: 영단어 타이핑 게임, 스페인어 단어 매칭)
- 게임과 스터디 존 자체가 **포트폴리오의 대표 프로젝트**가 됨 — "제가 만든 걸 직접 플레이해 보세요"는 어떤 스크린샷보다 강력함
- 공통 디자인 시스템(색·폰트·컴포넌트)으로 전체가 하나의 브랜드처럼 보이게 함

## 🗺️ 추천 로드맵 (단계별)

### 1단계 — 뼈대 (1주차)
- [ ] 기술 스택 확정 (→ 04 문서 참고, GitHub Pages 배포 전제)
- [ ] 디자인 시스템 정의: 컬러 팔레트, 폰트(Pretendard 추천), 다크모드
- [ ] 메인 허브 페이지 + 3개 섹션 라우팅 골격
- [ ] GitHub Pages 자동 배포 설정

### 2단계 — 첫 번째 "와우" (2주차)
- [ ] 미니게임 1개 완성 (간단하지만 중독성 있는 것 — 01 문서의 아이디어 목록 참고)
- [ ] 어학: 플래시카드 + 매일 단어 기능 (Web Speech API로 발음 듣기 — 무료!)
- [ ] 포트폴리오: 히어로 섹션 + 프로젝트 카드

### 3단계 — 살 붙이기 (3~4주차)
- [ ] 게임 2~3개 추가, 로컬 랭킹 + 결과 SNS 공유 기능
- [ ] 어학: 간격 반복(SRS) 복습 시스템, 스트릭(연속 학습) 캘린더
- [ ] 스크롤 애니메이션, 마이크로 인터랙션으로 완성도 업

### 4단계 — 대박 디테일 (5주차~)
- [ ] Lighthouse 90+ 점수, 모바일 완벽 대응
- [ ] OG 이미지 (링크 공유 시 예쁘게 보이기)
- [ ] 발음 연습(음성 인식), 리더보드(Supabase 무료 티어) 등 심화 기능

## ⭐ "누가 봐도 대박"을 만드는 7가지 원칙

1. **첫 3초** — 접속하자마자 움직임과 개성이 보여야 함 (히어로 애니메이션, 인터랙티브 요소)
2. **직접 만져보게** — 설명 대신 바로 플레이/학습 가능한 데모
3. **작지만 완벽하게** — 어설픈 기능 10개보다 완성도 높은 기능 3개
4. **모바일 퍼스트** — 방문자 절반 이상은 폰으로 봄
5. **공유 욕구** — 게임 결과·학습 스트릭을 자랑하고 싶게 (워들의 성공 비결)
6. **속도** — 3초 안에 뜨지 않으면 떠남
7. **일관된 브랜드** — 색·폰트·말투가 사이트 전체에서 통일
