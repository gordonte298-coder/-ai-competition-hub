## 1. 성공 사례 벤치마킹

### 1.1 Duolingo — 게이미피케이션의 교과서

세계 최대 어학 앱(기업가치 $6B+). 성공의 핵심은 "학습 효과"보다 **"매일 돌아오게 만드는 습관 설계"**다. 2026년 기준 DAU 전년 대비 36% 성장, 서구 시장 이탈률 28%로 최저치 기록.

| 메커니즘 | 작동 방식 | 왜 효과적인가 |
|---|---|---|
| **스트릭(Streak)** | 매일 1레슨 이상 완료 시 연속 일수 증가 | 7일 스트릭 유지 사용자는 장기 잔존율 **3.6배**. 손실 회피(loss aversion) 심리 활용 |
| **스트릭 프리즈** | 하루 빠져도 스트릭을 지켜주는 아이템 | 스트릭 붕괴 위기 사용자의 이탈을 **21% 감소** |
| **XP** | 레슨 완료 즉시 XP 지급 (화면 닫기 전에 보상 표시) | 행동과 보상의 즉각적 결합 → 도파민 루프 |
| **리그(Leagues)** | Bronze→Diamond 10개 디비전, 주간 30명 리더보드. 상위 승급/하위 강등, 월간 Diamond Tournament | 경쟁심 + 강등 공포로 주간 활동량 유지 |
| **하트/에너지** | 과거: 오답 시 하트 차감. 2026년 개편: 무료 사용자는 문제 풀 때마다 소모되는 에너지 25개 | 실수 비용 부과 + 유료 전환 압박 (희소성 설계) |
| **일일 퀘스트/이벤트** | 시간 제한 챌린지, 시즌 이벤트, 친구 스트릭 | 변동 보상(variable reward)으로 지루함 방지 |

## 2. 학습 과학: 간격 반복(Spaced Repetition)과 액티브 리콜

### 2.1 세 가지 핵심 원리

1. **간격 반복(Spaced Repetition)**: 망각 곡선(Ebbinghaus)에 따라 잊어버리기 직전에 복습 → 최소 노력으로 장기 기억화.
2. **액티브 리콜(Active Recall)**: 다시 읽기(수동)가 아니라 **인출 연습**(빈칸 채우기, 퀴즈, 받아쓰기)이 기억을 강화. 모든 학습 기능은 "보여주기"가 아니라 "떠올리게 하기"로 설계할 것.
3. **몰입/이해 가능한 입력(Comprehensible Input)**: 학습자 수준보다 약간 어려운(i+1) 실제 콘텐츠를 대량으로 읽고 듣기. LingQ가 이 원리의 구현체.

### 2.2 SM-2 알고리즘 (고전, 구현 초간단)

SuperMemo의 1987년 알고리즘. Anki의 원조 알고리즘이며 30줄이면 구현 가능.

```javascript
// SM-2: quality는 0~5 (사용자 자기 평가)
function sm2(card, quality) {
  let { repetition = 0, interval = 0, efactor = 2.5 } = card;
  if (quality >= 3) {                       // 정답
    if (repetition === 0) interval = 1;
    else if (repetition === 1) interval = 6;
    else interval = Math.round(interval * efactor);
    repetition += 1;
  } else {                                  // 오답 → 처음부터
    repetition = 0;
    interval = 1;
  }
  efactor = Math.max(1.3,
    efactor + (0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02)));
  const due = new Date(Date.now() + interval * 24 * 60 * 60 * 1000);
  return { repetition, interval, efactor, due };
}
```

### 2.3 FSRS — 2026년 표준 알고리즘

**FSRS(Free Spaced Repetition Scheduler)**는 DSR(Difficulty, Stability, Retrievability) 메모리 모델 기반의 머신러닝 최적화 알고리즘. SM-2보다 복습 횟수를 20~30% 줄이면서 같은 기억률을 달성한다고 알려져 있으며, Anki에 공식 탑재됨.

- 알고리즘 저장소: https://github.com/open-spaced-repetition/free-spaced-repetition-scheduler
- 조직 (다언어 구현체 모음): https://github.com/open-spaced-repetition

**JavaScript/TypeScript 구현체 — `ts-fsrs` (그대로 가져다 쓰면 됨)**:
- GitHub: https://github.com/open-spaced-repetition/ts-fsrs
- 문서: https://open-spaced-repetition.github.io/ts-fsrs/
- ESM/CJS/UMD 지원 → 브라우저에서도 Node에서도 동작. 경량 구현체로 https://github.com/AustinShelby/simple-ts-fsrs 도 있음.

```bash
npm install ts-fsrs
```

```typescript
import { createEmptyCard, fsrs, generatorParameters, Rating } from "ts-fsrs";

const params = generatorParameters({
  enable_fuzz: true,
  request_retention: 0.9,   // 목표 기억률 90%
});
const scheduler = fsrs(params);

let card = createEmptyCard(new Date()); // 새 카드 생성

// 사용자가 카드를 평가: Again(1) / Hard(2) / Good(3) / Easy(4)
const schedulingCards = scheduler.repeat(card, new Date());
const next = schedulingCards[Rating.Good];
card = next.card;                        // 갱신된 카드 (due, stability, difficulty 포함)
console.log(card.due);                   // 다음 복습 예정일 → DB에 저장

// 매일 복습 큐 만들기: due <= 오늘 인 카드만 SELECT
```

**DB 스키마 최소 설계** (카드 한 장당):

```sql
CREATE TABLE cards (
  id INTEGER PRIMARY KEY,
  user_id INTEGER,
  front TEXT, back TEXT,            -- 단어 / 뜻+예문
  due TIMESTAMP,                    -- 다음 복습일 (핵심 인덱스)
  stability REAL, difficulty REAL,  -- FSRS 상태
  reps INTEGER, lapses INTEGER,
  state INTEGER,                    -- New/Learning/Review/Relearning
  last_review TIMESTAMP
);
CREATE INDEX idx_due ON cards(user_id, due);
```

> **팁**: 4버튼(Again/Hard/Good/Easy)이 부담스러우면 Duolingo처럼 **정답/오답 2단계**로 단순화해도 됨 (오답=Again, 정답=Good으로 매핑).

### 3.3 TTS — Web Speech API (무료, 브라우저 내장, 서버 비용 0원)

`speechSynthesis`는 **모든 주요 브라우저**(Chrome/Edge/Safari/Firefox)에서 지원. 어학 사이트의 단어/문장 읽어주기를 API 비용 없이 구현할 수 있는 최고의 무기.

- MDN 문서: https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API
- 사용 가이드: https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API/Using_the_Web_Speech_API

```javascript
// 단어/문장 발음 재생 (영어·스페인어 등 언어 지정)
function speak(text, lang = "en-US", rate = 0.9) {
  const u = new SpeechSynthesisUtterance(text);
  u.lang = lang;              // "es-ES", "es-MX", "en-GB" 등
  u.rate = rate;              // 0.5~1.0: 학습자용 천천히 재생
  const voices = speechSynthesis.getVoices();
  u.voice = voices.find(v => v.lang === lang) ?? null;
  speechSynthesis.cancel();   // 이전 재생 중단
  speechSynthesis.speak(u);
}
speak("¿Dónde está la biblioteca?", "es-ES");
```

**주의사항**:
- `getVoices()`는 비동기 로드 → `speechSynthesis.onvoiceschanged` 이벤트에서 목록 갱신.
- 데스크톱 Chrome에서 200~250자 이상 utterance는 잘릴 수 있음 → 문장 단위로 쪼개서 큐잉.
- 음성 품질을 높이고 싶으면 유료 대안: Google Cloud TTS(월 100만 자 무료), Amazon Polly.

### 3.4 음성 인식 — SpeechRecognition API (발음 연습용)

- Chrome/Edge/Opera 완전 지원, Safari 14.1+ (`webkitSpeechRecognition` 접두사), Firefox는 기본 비활성.
- Chrome은 오디오를 구글 서버로 전송해 인식하므로 **인터넷 연결 필수**.

```javascript
const SR = window.SpeechRecognition || window.webkitSpeechRecognition;
const rec = new SR();
rec.lang = "es-ES";
rec.interimResults = false;

rec.onresult = (e) => {
  const said = e.results[0][0].transcript.toLowerCase();
  const target = "buenos días";
  // 초간단 채점: 편집 거리 기반 유사도 (실전엔 fastest-levenshtein 등 사용)
  const score = similarity(said, target);        // 0~1
  showFeedback(score > 0.8 ? "훌륭해요!" : `다시: "${said}"로 들렸어요`);
};
rec.start(); // 사용자 제스처(버튼 클릭) 안에서 호출해야 함
```

## 4. 구현할 만한 학습 기능 아이디어

MVP부터 확장까지, 난이도 순:

### 4.1 기본 (MVP)
1. **플래시카드 + SRS**: `ts-fsrs`로 스케줄링. 앞면 단어 → 뒷면 뜻+예문(Tatoeba)+발음(Web Speech TTS). "오늘 복습할 카드 N장" 큐.
2. **4지선다 단어 퀴즈**: 정답 1 + 같은 빈도대의 오답 3(빈도 리스트에서 추출). 액티브 리콜 효과.
3. **매일 단어(Word of the Day)**: Wordnik의 WOTD API 또는 빈도 리스트 순회. 이메일/푸시 없이도 재방문 유도 장치.
4. **스트릭 캘린더**: GitHub 잔디 스타일 히트맵. 날짜별 학습량을 색 농도로 표시.

### 4.2 중급
5. **문장 배열 게임 (Word Bank)**: Tatoeba 문장을 단어 단위로 셔플 → 드래그/탭으로 순서 맞추기. Duolingo의 대표 문제 유형.
   ```javascript
   const sentence = "Yo quiero aprender español";
   const tokens = sentence.split(" ").sort(() => Math.random() - 0.5);
   // + 함정 단어(distractor) 2~3개 섞기
   ```
6. **받아쓰기(Dictation)**: TTS로 문장 재생 → 입력 → diff 채점(단어 단위 비교, 틀린 부분 하이라이트). 듣기+철자 동시 훈련.
7. **빈칸 채우기(Cloze)**: 예문에서 학습 단어를 `___`로 치환. Clozemaster(https://www.clozemaster.com/)가 이 하나로 성공한 서비스.
8. **발음 연습**: TTS로 모범 발음 → SpeechRecognition으로 사용자 발화 인식 → 편집 거리 유사도로 점수화 (3.4절 코드).

### 4.3 고급 (차별화)
9. **몰입 리더 (LingQ 스타일)**: 공개 도메인 텍스트를 문단별 표시, 단어 클릭 → 사전 API 팝업 → "저장" 시 자동으로 SRS 카드 생성. 단어 상태(모름/학습중/앎)를 색으로 표시.
10. **듣기 플레이어**: LibriVox 오디오북 + Gutenberg 텍스트 싱크, 문장 반복 재생 버튼.
11. **레벨 테스트**: CEFR 레벨별 단어 샘플로 어휘량 추정 → 시작 레벨 배정 (Busuu 방식).

## 5. 게이미피케이션 설계

### 5.1 설계 원칙: Hook 모델 (트리거 → 행동 → 변동 보상 → 투자)

중독성 있는 루프의 공식:
- **트리거**: 매일 단어 알림, 스트릭 위기 경고("스트릭이 3시간 후 사라져요!")
- **행동**: 5분 이내로 끝나는 짧은 레슨 (마찰 최소화 — 이게 Duolingo의 진짜 비밀)
- **변동 보상**: XP 2배 타임, 랜덤 보너스 상자, 리그 순위 변동
- **투자**: 스트릭·XP·수집한 뱃지가 쌓일수록 떠나기 아까워짐 (매몰 비용)

### 5.2 요소별 설계 가이드

| 요소 | 설계 지침 | 함정 |
|---|---|---|
| **XP** | 완료 **즉시** 애니메이션과 함께 지급. 정답률 보너스, 연속 정답 콤보 | XP만으로는 2주 내 식상해짐 → 다른 요소와 결합 필수 |
| **레벨** | XP 누적 → 레벨업. 초반 레벨은 빨리(1~2일에 1렙), 후반은 느리게 (RPG식 곡선: `필요XP = 100 * level^1.5`) | 레벨이 아무것도 해금하지 않으면 무의미. 레벨별 기능/테마 해금 |
| **스트릭** | 하루 최소 목표(예: 카드 10장)로 달성 문턱을 낮게. **스트릭 프리즈** 반드시 제공(이탈 21% 감소 실증) | 목표가 높으면 스트릭이 스트레스가 되어 역효과 |
| **뱃지** | 2트랙: 개인 기록(단어 1000개 학습)·이벤트(주말 챌린지). 다음 뱃지까지 진행률 항상 노출 ("850/1000") | 너무 쉽게 다 따면 수집 동기 소멸 → 티어(동/은/금) 구조 |
| **리더보드** | 전체 순위 대신 **소규모 그룹(주간 30명) + 승급/강등**. 신규 유저가 고인물과 경쟁하지 않도록 리셋 주기 필수 | 전역 리더보드는 상위 1%만 즐겁고 99%는 좌절 |
| **하트/에너지** | 오답 비용 부과는 신중하게(무료 웹사이트라면 생략 권장 — 학습 의욕 저하 리스크) | Duolingo도 하트 시스템을 2026년 에너지제로 개편했을 만큼 논쟁적 |

### 5.3 스트릭 캘린더 + 스트릭 로직 예시

```javascript
// 스트릭 계산: 마지막 학습일 기준
function updateStreak(user, today = new Date()) {
  const last = user.lastStudyDate;                 // 'YYYY-MM-DD'
  const diffDays = dateDiffInDays(last, today);
  if (diffDays === 0) return user.streak;          // 오늘 이미 학습
  if (diffDays === 1) return ++user.streak;        // 연속!
  if (diffDays === 2 && user.streakFreezes > 0) {  // 프리즈 자동 사용
    user.streakFreezes--; return ++user.streak;
  }
  return (user.streak = 1);                        // 리셋
}
```

> **핵심 교훈**: 게이미피케이션은 "장식"이 아니라 **핵심 루프(오늘의 복습)를 매일 실행하게 만드는 장치**. 학습 목표(SRS due 카드 소화)와 게임 목표(스트릭 유지)를 일치시켜라.

## 7. 추천 기술 스택 및 MVP 로드맵

### 7.1 비용 0원 스택 예시

- **프론트엔드**: React/Next.js 또는 SvelteKit + Tailwind
- **SRS**: `ts-fsrs` (클라이언트에서 스케줄링 계산 가능)
- **저장소**: 초기엔 IndexedDB(로그인 없는 로컬 우선) → 성장 시 Supabase/PostgreSQL
- **TTS/음성인식**: Web Speech API (0원)
- **사전**: Free Dictionary API (0원, 키 없음)
- **예문/단어 DB**: Tatoeba 덤프 + FrequencyWords → 빌드 타임에 정적 JSON 생성
- **호스팅**: Vercel/Netlify/GitHub Pages 무료 티어

### 7.2 3단계 로드맵

**1단계 (MVP, 1~2주)**
- 빈도 상위 2,000단어 + Tatoeba 예문으로 코스 데이터 생성
- 플래시카드 + FSRS 복습 큐 + TTS 발음
- 4지선다 퀴즈, 스트릭 카운터 + 잔디 캘린더 (IndexedDB 저장)

**2단계 (게임화·다양화)**
- 문장 배열 게임, 받아쓰기, 빈칸 채우기
- XP/레벨/뱃지 시스템, 매일 단어
- 계정 시스템 + 서버 동기화

**3단계 (차별화)**
- 몰입 리더 (Gutenberg 텍스트 + 클릭 사전 + 자동 카드 생성)
- 발음 채점 (SpeechRecognition)
- 주간 리그 리더보드, 스페인어 동사 활용 트레이너

### 7.3 설계 시 반드시 기억할 것

1. **첫 세션 5분 안에 "배웠다"는 느낌**을 줘라 (회원가입 전에 레슨 먼저 — Duolingo의 온보딩 원칙).
2. 모든 기능은 **액티브 리콜**이어야 한다. 단어 목록 "보여주기"는 학습이 아니다.
3. 게이미피케이션의 목적은 단 하나: **SRS due 카드를 매일 소화하게 만드는 것**.
4. 데이터(빈도 리스트 × Tatoeba × CEFR)는 전부 공짜다 — 콘텐츠 제작비 없이 커리큘럼을 자동 생성하라.
5. Web Speech API 하나로 TTS와 발음 연습을 서버 비용 0원에 해결할 수 있다.
